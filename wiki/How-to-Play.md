# How to Play Neon Pulsar

**Neon Pulsar: Zero-G Arena** is by [Aarti S Ravikumar](https://ai-aarti.com/) with the [PCSS II Robotics Team](https://pcssiirobotics.org/). Return to the [main website](https://pcssiirobotics.org/) or the [Wiki home](https://github.com/aartisr/hackclub-neon-pulsar/wiki).

## Match objective

Fly into the white disc to pick it up. Throw the disc into the opposing team's colored goal. Team Cyan attacks the Magenta goal; Team Magenta attacks the Cyan goal. The first team to five points wins.

## Keyboard controls

| Key | Action |
| --- | --- |
| W, A, S, D | Move through the arena |
| Space / Shift | Rise / descend |
| E | Throw while carrying the disc |
| T / Y | Open everyone / team chat |
| Esc | Open or close the game menu |

Touch screens provide a flight stick, altitude controls, Throw, and chat buttons.

## Match flow

1. One player hosts an arena and shares the full room code or invite link.
2. Others join and select Team Cyan or Team Magenta.
3. The host starts the match.
4. Players collect and throw the disc until one team reaches five points.

See [Multiplayer and Chat](https://github.com/aartisr/hackclub-neon-pulsar/wiki/Multiplayer-and-Chat) for team switching, late joins, and leaving. The [GitHub Pages guide](https://aartisr.github.io/hackclub-neon-pulsar/) provides a separate readable version once published.
