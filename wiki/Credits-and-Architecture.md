## What the repository contains

The interface is built with React and TypeScript. Three.js renders the 3D arena. PeerJS uses WebRTC data connections for multiplayer. The host runs the authoritative simulation and broadcasts game state. Match replays and generated audio are part of the app. Career statistics are stored locally in the browser; the displayed leaderboard contains sample standings.
