Neon Pulsar: Zero-G Arena

A browser-based multiplayer zero-gravity disc game created by Aarti S Ravikumar with the PCSS II Robotics Team.

How to play

One player hosts an arena and shares the invite link. Others join the room and choose Team Cyan or Team Magenta. Fly into the white disc to pick it up, then throw it into the opposing team's colored goal. The first team to five points wins.

About the project

Neon Pulsar runs in a web browser and uses Three.js for 3D graphics and PeerJS for multiplayer connections. Read the game details and creator credits or inspect the source code.
