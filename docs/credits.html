Creator and credits

Neon Pulsar: Zero-G Arena was created by Aarti S Ravikumar, also known as Aarti Sri Ravikumar, with the PCSS II Robotics Team.

Project record

The source repository contains the implementation, README, and development history. The main website presents the PCSS II Robotics Team, while Aarti's portfolio provides the author's identity and broader work.

Implementation

The browser interface uses React and TypeScript. Three.js renders the arena. PeerJS establishes WebRTC multiplayer data connections. The host runs the authoritative game simulation. The project also includes match replays and locally stored career statistics. The displayed leaderboard uses sample standings, not a persistent global ranking service.
