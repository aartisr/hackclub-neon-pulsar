Project guide

Fly. Catch. Score.

Neon Pulsar is a browser-based multiplayer zero-gravity disc game created by Aarti S Ravikumar with the PCSS II Robotics Team. The first team to score five goals wins.

Quick start

  1. One player hosts an arena and shares its invite link.
  2. Others join the same room and choose Cyan or Magenta.
  3. The host starts the match. Fly into the white disc, then throw it into the other team's colored goal.

Visit the PCSS II Robotics Team's main website for the wider team, or Aarti S Ravikumar's portfolio for the author. For this game's own public description, see the About and credits source page.
